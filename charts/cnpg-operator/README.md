# cnpg-operator

**CloudNativePG** — оператор для PostgreSQL в Kubernetes: создаёт и сопровождает кластеры БД, репликацию, переключение при сбоях и резервное копирование.

Сначала установите этот чарт, затем — `cnpg-cluster` для конкретной базы.

Соглашения: [chart-conventions.md](../../docs/chart-conventions.md).
