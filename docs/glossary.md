# Глоссарий

Краткие определения терминов, которые встречаются в документации [community-marketplace](../README.md).

| Термин | Значение |
|--------|----------|
| **Штурвал** | Платформа управления Kubernetes-сервисами; установка прикладов через CR **ShturvalServiceConfig (SSC)** и каталог Helm-чартов. |
| **ShturvalRepoConfig** | Cluster-scoped CR (`ops.shturval.tech/v1beta2`): URL репозитория Helm (`https://…/index.yaml`, `oci://…` или Nexus/Harbor). После применения чарты видны в UI: *Сервисы и репозитории → Доступные чарты*. |
| **ShturvalServiceConfig (SSC)** | CR установки конкретного чарта: имя, версия, namespace, репозиторий (`reponame`), зависимости от других SSC, `customvalues`. |
| **Чарт-обёртка (wrapper)** | Helm-чарт маркетплейса с зависимостью на upstream-чарт; зависимость хранится в git как `charts/*.tgz` для офлайн-сборки. |
| **Оператор и экземпляр** | Оператор (например `cnpg-operator`) ставит CRD и контроллер; экземпляр (`cnpg-cluster`) создаёт конкретный кластер БД. Экземпляр обычно зависит от SSC оператора. |
| **Закрытый контур (air-gap)** | Среда без доступа в интернет с рабочей станции; образы и чарты доставляются **бандлом** и загружаются во внутренние реестры скриптом `push-offline.sh`. |
| **Бандл** | Архив `airgap-bundle.tar.gz`: упакованные чарты, `index.yaml`, tar-образы, `push-offline.sh`, опционально базы для локального сканирования. |
| **HTTP-репозиторий Helm** | Классический index: URL отдаёт `index.yaml` и ссылки на `.tgz` (GitHub Pages, Nexus hosted, ChartMuseum). Удобен для UI Штурвала. |
| **OCI-репозиторий** | Чарты и образы в container registry (`oci://registry/…/charts`). Для OCI список чартов в UI Штурвала может не подгружаться — имя чарта задаётся в SSC вручную. |
| **Trivy** | Сканер уязвимостей образов и конфигураций; в CI используется база `public.shturval.tech/trivy-db:2`. |
| **БДУ ФСТЭК** | Банк данных угроз; выгрузка `vulxml` сопоставляет CVE с идентификаторами `BDU:YYYY-NNNNN` и уровнем по формулировке ФСТЭК. |
| **Отпечаток исходников** | Файл `build-fingerprint.txt` в релизе бандла: хеши `charts/` и `images/` в git плюс digest upstream-образов. Меняется при изменении исходников, **не** при смене списка CVE. |
